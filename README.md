# Salon Research Project

##  Project Overview

**Salon Research Project** is a research-based project conducted to study real-world salon businesses within the **Colombo Municipal Council area**.

The project focuses on understanding salon operations and identifying factors that may influence **customer satisfaction and service quality**. As part of the research, real-world data was collected through surveys and organized into a structured database.

A major component of the project was the design and implementation of a **relational database using SQL**. The project included **Entity-Relationship (ER) modeling, database design, data organization, SQL queries, and data analysis**. Excel and Python were also used to support data preparation, analysis, and visualization.

The project demonstrates how database management and data analysis techniques can be applied to a real-world business research problem.

##  Project Objectives

The main objectives of this project were to:

* Study real-world salon businesses within the Colombo Municipal Council area.
* Collect and organize salon-related data using surveys.
* Identify factors that may influence customer satisfaction.
* Design a structured relational database for the collected information.
* Develop an Entity-Relationship (ER) model representing the database structure.
* Store and manage the collected data using SQL.
* Perform SQL queries to retrieve and analyze relevant information.
* Use data analysis and visualization to identify useful patterns and insights.
* Provide recommendations that could support improvements in salon management and operations.

##  Research Methodology

The project followed a structured research and database development process:

### 1. Research & Data Collection

Information was collected from real-world salon environments within the Colombo Municipal Council area. Surveys were used to gather relevant information about salon services, customer experiences, and factors related to satisfaction.

### 2. Data Preparation

The collected information was reviewed, organized, and prepared before being incorporated into the database. Data cleaning and structuring were performed to improve consistency and usability.

### 3. ER Modeling

An **Entity-Relationship (ER) model** was developed to represent the relationships between the different entities involved in the salon management system.

The ER model helped define:

* Entities
* Attributes
* Primary keys
* Foreign keys
* Relationships between entities

### 4. Database Design

Based on the ER model, a relational database structure was designed. The database was structured to allow salon-related information to be stored and retrieved efficiently.

### 5. SQL Implementation

SQL was used to create and manage the database and perform queries on the collected data.

The SQL component included tasks such as:

* Creating database tables
* Defining primary and foreign keys
* Inserting data
* Retrieving records
* Filtering and sorting data
* Joining related tables
* Aggregating information
* Generating meaningful results from the database

### 6. Data Analysis & Visualization

Excel and Python were used alongside SQL to support data analysis and visualization. The results were examined to identify patterns related to customer satisfaction and salon operations.

### 7. Findings & Recommendations

The results were interpreted to identify areas that could potentially improve customer satisfaction, service quality, and salon operations.
